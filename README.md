# E-Commerce Data Analytics Portfolio (`CleanedEcommerce`)

End-to-end data analytics projects (Assignments 1–4) analyzing the `CleanedEcommerce` dataset across **1,200 orders** and **7 product lines** using **Microsoft Excel**, **SQL**, and **SCR Data Visualization**.

## Repository Contents

- **`Cleaned Data.xlsx`** — Consolidated cleaned dataset containing order status, product revenue, and core KPI metric tabs (Assignments 1 & 2).
- **`Project 1 Change Log Summary.pdf`** — Data cleaning audit log documenting standardization, validation, and anomaly checks.
- **`Project 2 Executive Summary.pdf`** — KPI modeling and top-line business performance summary.
- **`Project 3 SQL Analysis Report.pdf`** — SQL querying report with query outputs and revenue/status breakdowns.
- **`Project 3 SQL Analysis.sql`** — SQL queries run during the fulfillment and revenue audit.
- **`Project 4 CleanedEcommerce Charts Final.xlsx`** — Finalized spotlight charts workbook (`Product Gross`, `Order Status`, `Gross vs Net`, and `VIP Outliers`).
- **`Project 4 Ecommerce Revenue Fulfillment Audit SCR.pptx`** — 6-slide executive presentation structured using the Situation–Complication–Resolution (SCR) framework.

## Key Analytical Findings

- **Gross Revenue Baseline:** **$1.26M** (`$1,264,761.96`) across `1,200` orders, with core hardware lines (**Chair**, **Printer**, **Laptop**, **Tablet**) driving **60.9%** (`$769.9K`) of gross volume.
- **Revenue Attrition:** **41.1%** (`$519.7K` across `497` orders) is lost to **Cancelled** (`$276.4K`, `21.9%`) and **Returned** (`$243.3K`, `19.2%`) orders.
- **Net Revenue Rank Flip:** **Printer** leads net realized revenue at **$121.0K** (`61.9%` retention), overtaking **Chair** (**$120.3K** net) despite slightly lower gross sales.
- **VIP Bulk Order Friction:** **4 of the top 8** high-value orders (`50.0%`, totaling **$13,498.45** lost out of **$27,033.40**) ended in cancellation or return.
- **Strategic Opportunity:** Targeted fixes across VIP order confirmation, low-retention product QA, and pending dispatch SLAs can recover an estimated **$155K–$210K** in annual net revenue.
